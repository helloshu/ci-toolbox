## build-a

Android artifact built from the pinned commit with `targets/kg/patches/` applied:

- `a-universal.apk` — entitlement unlocked, telemetry removed
- `kg-source.tar.gz` — corresponding patched source

Signed with a self-signed certificate, so any previous install of the same package
has to be uninstalled first.
